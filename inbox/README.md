# Inbox

Nowe materiały czekające na przetworzenie: linki do filmów, zdjęcia notatek, wypisy z rozmów.

Przetworzenie = wiersz w `rejestry/zrodla.md` + notatka w `zrodla/notatki/` + kandydaci we właściwych folderach. Po przetworzeniu plik z inboxu usuwamy.

`inbox/_surowe/` jest poza gitem — tu trafiają pełne transkrypcje i PDF-y katalogów.
