# Decyzje pracowni

Jeden plik na decyzję: `DEC-NNN.md`, z szablonu [`szablony/decyzja.md`](../../szablony/decyzja.md).

Decyzja zapisuje **mój wybór spośród poprawnych opcji** (np. dno między bokami, plecy we wpust, domowy system szuflad). Reguły wynikające z decyzji mają `pochodzenie: standard-pracowni` i wskazują decyzję w `powiazania.zalezy_od`.

Decyzja ma status `proponowana`, dopóki Michał jej nie przyjmie. Zmiana decyzji = nowa decyzja, stara dostaje `zastapiona_przez`.
