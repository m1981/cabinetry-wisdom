# Konflikty

Jeden plik na konflikt: `KONF-NNN.md`, z szablonu [`szablony/konflikt.md`](../../szablony/konflikt.md).

Wpisy w sporze dostają status `sporna` i odsyłacz w `powiazania.konflikt`. Zatwierdzić można je dopiero po rozstrzygnięciu konfliktu.

Natury konfliktu i sposób rozstrzygania — [PLAN.md, rozdz. 8.1](../../PLAN.md).

Lista otwartych i rozstrzygniętych konfliktów jest w [INDEKS.md](../../INDEKS.md).
