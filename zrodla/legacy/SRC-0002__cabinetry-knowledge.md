# Wiedza stolarska o zabudowie kuchennej

Status: draft. Wersja: 0.7. Data opracowania: 2026-10-02.

Ten plik zawiera wspólny słownik pojęć dotyczących konstrukcji szafek kuchennych, blatów i montażu zabudowy. Reguły technologiczne i wymiarowe oraz ustalenia z dostarczonych materiałów zapisujemy w osobnym [rejestrze](cabinetry-rules.md). Słownik obejmuje również nazwy warsztatowe, które mogą różnić się między wykonawcami.

Definicje są roboczą syntezą wiedzy ogólnej autora. Przy wybranych hasłach podano dokumentację producenta potwierdzającą wskazane znaczenie lub rozróżnienie. Hasło bez odsyłacza nie zostało w tym przyroście osobno zweryfikowane w źródle zewnętrznym. Nie przeprowadzono jeszcze rozmowy ze stolarzem ani walidacji nazewnictwa konkretnego warsztatu. Dokument nie ustanawia zatwierdzonych reguł wykonawczych.

## Zabudowa i rodzaje szafek

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Zabudowa kuchenna | Zespół szafek, frontów, blatów, elementów wykończeniowych i rozwiązań mocowania, dopasowany do pomieszczenia oraz urządzeń. |
| Ciąg szafek | Grupa szafek ustawionych obok siebie wzdłuż określonej linii; jej długość obejmuje także przewidziane wypełnienia i odstępy. |
| Szafka dolna, stojąca | Szafka znajdująca się w dolnej części zabudowy, często pod blatem; sposób podparcia lub zamocowania określa konstrukcja. |
| Szafka górna, wisząca | Szafka umieszczona nad dolnym ciągiem lub blatem i zamocowana do odpowiedniego podłoża. |
| Szafka wysoka, słupek | Wysoki korpus przeznaczony np. do przechowywania albo zabudowy urządzeń; „słupek” nie oznacza jednej ustalonej wysokości. |
| Szafka narożna | Szafka obsługująca narożnik zabudowy; jej kształt, dostęp i mechanizm wewnętrzny wymagają odrębnego określenia. |
| Szafka zlewozmywakowa | Szafka przewidziana pod zlewozmywak, z miejscem na jego komorę, odpływ i pozostałe wyposażenie. |
| Szafka pod urządzenie | Korpus przewidziany dla konkretnego AGD. Nie każde urządzenie do zabudowy ma własny korpus meblowy. |
| Wyspa | Zabudowa wolnostojąca, dostępna z kilku stron i niezłączona bezpośrednio z ciągiem przyściennym. |
| Półwysep | Część zabudowy wychodząca w pomieszczenie i połączona jednym końcem z inną zabudową lub ścianą. |
| Moduł szafki | Umowna jednostka planowania. Trzeba określić, czy jego szerokość oznacza korpus, zajęte miejsce czy wymiar systemowy. |

## Elementy korpusu i wykończenia

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Korpus | Konstrukcyjna obudowa szafki, złożona z połączonych elementów. Front, blat i cokół opisujemy oddzielnie. |
| Bok korpusu | Pionowa ściana boczna szafki; odróżniamy ją od dodatkowego panelu dekoracyjnego. |
| Bok widoczny | Bok zakwalifikowany w danym układzie jako eksponowany. To określenie jego położenia i wykończenia w projekcie, nie osobny typ konstrukcji. Przykład klasyfikacji: [STOL-011](cabinetry-rules.md#STOL-011). |
| Bok niewidoczny | Bok zakwalifikowany jako osłonięty w danym układzie, np. przy bocznej ścianie. Samo określenie nie ustala materiału lub sposobu wykończenia. Przykład: [STOL-012](cabinetry-rules.md#STOL-012). |
| Wieniec dolny, dno korpusu | Dolny poziomy element zamykający korpus. Określenie „dno” wymaga wskazania, czy chodzi o korpus, czy szufladę. |
| Wieniec górny | Górny poziomy element zamykający korpus. Może występować pełna płyta albo inne rozwiązanie, np. trawersy. |
| Trawers, listwa spinająca | Wąski element łączący boki korpusu, często w miejscu pełnego wieńca. Jego funkcję i położenie trzeba opisać na rysunku. Nazwę „belka” z tabel filmu 2 zachowujemy jako nazwę źródłową; przyporządkowanie do trawersu jest robocze, bez ustalenia miejsca montażu — [STOL-023](cabinetry-rules.md#STOL-023). |
| Plecy, ścianka tylna | Element zamykający tył korpusu. Może również usztywniać szafkę, zależnie od materiału i sposobu połączenia. |
| Przegroda | Wewnętrzny element dzielący korpus na części; tutaj nazwę uzupełniamy o orientację pionową lub poziomą. |
| Półka stała | Poziomy element połączony z korpusem w określonym położeniu; może pełnić funkcję konstrukcyjną. |
| Półka przestawna | Półka wsparta na podpórkach, z możliwością zmiany położenia według przygotowanych punktów podparcia. |
| Cokół maskujący | Panel przy podłodze, zasłaniający przestrzeń pod szafkami. Odróżniamy go od podstawy nośnej. Diagram źródłowy „Cokoły dolne” określa frontowe odcinki C1/C2 i odcinek C3 przy lewym zakończeniu — [STOL-044](cabinetry-rules.md#STOL-044); nie ustala konstrukcji nośnej. |
| Cokół nośny, podstawa skrzyniowa | Konstrukcja pod korpusami przenosząca ich obciążenie na podłogę. Nazwa „cokół” bez doprecyzowania jest niejednoznaczna. |
| Nóżka regulowana | Podpora korpusu z możliwością zmiany wysokości ustawienia. |
| Blenda, wypełnienie | Element wypełniający przewidzianą przerwę, np. między szafką a ścianą. W opisach warsztatowych trzeba odróżnić go od innych maskownic. Przykład użycia nazwy: [IKEA][I1]. |
| Blenda szafkowa, bok jako blenda | W filmie 2 nazwa dotyczy boków wskazanych jako widoczne; szafka 1 ma podpis „lewy bok jako blenda”. Wymiary zestawienia odpowiadają wysokości i głębokości boku. Nie utożsamiamy tej nazwy z wypełnieniem szczeliny przy ścianie ani z obowiązkową dodatkową płytą — [STOL-020](cabinetry-rules.md#STOL-020), [STOL-021](cabinetry-rules.md#STOL-021). Film 3 określa wykończenie części takich boków — [STOL-028](cabinetry-rules.md#STOL-028). |
| Panel boczny dekoracyjny | Dodatkowy panel wykańczający widoczny bok zabudowy; nie zakładamy, że zastępuje bok konstrukcyjny. |
| Maskownica | Ogólna nazwa elementu zasłaniającego szczelinę, mocowanie lub instalację. W regule potrzebne są jego funkcja i miejsce. |

## Fronty i geometria otwierania

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Front | Widoczny element zamykający dostęp do wnętrza albo osłaniający urządzenie; może być drzwiami, klapą lub frontem szuflady. |
| Front pełny | W tabeli filmu 3 określenie rodzaju frontu jako „pełny”, bez wskazania przeszklenia. Nie ustala rdzenia, grubości ani konstrukcji — [STOL-028](cabinetry-rules.md#STOL-028). |
| Uchwyt zintegrowany | Uchwyt przewidziany jako część rozwiązania frontu. Nazwa sama nie rozstrzyga profilu, frezowania ani materiału; film 3 stosuje ją jako wariant modelu frontu — [STOL-028](cabinetry-rules.md#STOL-028). |
| Front nakładany | Front zamknięty przed czołowymi krawędziami korpusu, przykrywający je w określonym zakresie. Geometrię nałożenia pokazuje [Blum][B1]. |
| Front wpuszczany | Front mieszczący się w otworze korpusu, między otaczającymi go elementami, zamiast przykrywać ich czołowe krawędzie. |
| Front półnakładany | Front przykrywający część krawędzi wspólnej przegrody, przy której pracuje także drugi front. Nie znaczy „front otwarty do połowy”. |
| Nałożenie frontu | Wymiar, o jaki front przykrywa czołową krawędź boku lub przegrody; oznaczenie w katalogu Blum: FA. [Blum][B1]. |
| Szczelina między frontami, fuga | Odstęp między sąsiednimi frontami w zamknięciu. Odróżniamy go od przestrzeni wymaganej podczas otwierania. |
| Luz ruchowy | Wolna przestrzeń potrzebna, aby ruchomy element nie kolidował z korpusem, sąsiednim frontem, uchwytem lub ścianą. |
| Drzwi lewe lub prawe | W tym dokumencie, patrząc na zamknięty front od strony użytkownika: lewe mają zawiasy po lewej, prawe po prawej. Dostawca może używać innej konwencji. |
| Klapa | Front otwierany w ruchu unoszenia, opuszczania albo składania według zastosowanego mechanizmu. |
| Kąt otwarcia | Kąt, który osiąga front względem położenia zamkniętego. Nie określa samodzielnie dostępnej przestrzeni wewnątrz. |
| Obwiednia ruchu | Obszar zajmowany przez front, uchwyt lub mechanizm w całym przebiegu otwierania; służy do opisu kolizji. |

## Materiały i obróbka

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Płyta wiórowa | Materiał drewnopochodny wytworzony z wiórów połączonych spoiwem; rodzaj płyty i jej wykończenie opisujemy oddzielnie. |
| Płyta melaminowana, potocznie laminowana | Płyta z powierzchnią dekoracyjną na bazie papieru impregnowanego żywicą melaminową. Potoczne „laminowana” może oznaczać też płytę oklejoną oddzielnym laminatem. |
| MDF | Płyta z włókien drzewnych o średniej gęstości; nazwa nie określa sama odporności na wilgoć ani wykończenia. |
| HDF | Płyta z włókien drzewnych o wysokiej gęstości; nazwa nie określa sama grubości ani przeznaczenia. |
| Sklejka | Płyta z połączonych warstw forniru, zwykle o krzyżujących się kierunkach włókien kolejnych warstw. |
| Drewno lite | Materiał z drewna, w odróżnieniu od płyt z wiórów lub włókien; element może być wykonany z jednego kawałka albo klejony. |
| Fornir | Cienki arkusz drewna stosowany jako okładzina; nie oznacza dekoru drukowanego imitującego drewno. |
| Laminat HPL | Laminat dekoracyjny prasowany pod wysokim ciśnieniem. Cienka okładzina HPL i laminat kompaktowy są różnymi postaciami materiału. |
| Laminat kompaktowy | Grubszy laminat z własnym zwartym rdzeniem; odróżniamy go od cienkiej okładziny naklejonej na płytę wiórową. Przykład rodziny materiałów: [EGGER][E2]. |
| Obrzeże | Materiał wykańczający wąską powierzchnię płyty, np. z ABS, PP lub drewna. Zakres zastosowania obrzeży opisuje [EGGER][E1]. |
| Oklejanie krawędzi | Operacja przyklejenia i obróbki obrzeża na krawędzi elementu. „Okleina” bez doprecyzowania może oznaczać też materiał na dużą powierzchnię. |
| Dekor i kierunek wzoru | Dekor określa wygląd powierzchni; kierunek wzoru, np. imitowanego usłojenia, określa jej orientację na elemencie. |
| Usłojenie poziome | Pozioma orientacja wzoru względem elementu w pozycji użytkowej; w filmie 3 parametr frontów i części blend z płyty meblowej. Sam dekor Dąb sonoma nie dowodzi użycia drewna litego — [STOL-028](cabinetry-rules.md#STOL-028). |
| Rzaz | Szerokość materiału usuwanego przez narzędzie tnące podczas cięcia. |
| Naddatek obróbkowy | Materiał pozostawiony ponad wymiar końcowy, przewidziany do usunięcia w dalszej obróbce. |
| Rowek, wręg, faza | Rowek to podłużne zagłębienie; wręg to schodkowe wybranie przy krawędzi; faza to ścięcie krawędzi. To trzy różne geometrie. |

## Połączenia i okucia

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Okucie | Element mechaniczny służący do łączenia, mocowania, podpierania lub poruszania częściami mebla. |
| Kołek meblowy | Łącznik osadzany w przygotowanych otworach, np. drewniany kołek łączący elementy korpusu. Odróżniamy go od kołka mocującego do ściany. |
| Konfirmat | Wkręt meblowy o geometrii przeznaczonej do łączenia elementów płytowych; sposób wiercenia zależy od jego wymiarów. |
| Złącze mimośrodowe | Złącze, w którym obrót mimośrodu zaciska współpracujący trzpień. Nie każda konstrukcja złącza ma tę samą geometrię wiercenia. |
| Zawias puszkowy | Zawias z częścią osadzaną w otworze frontu oraz częścią współpracującą z mocowaniem do korpusu. [Blum][B1]. |
| Prowadnik zawiasu | Element montowany do korpusu i współpracujący z ramieniem zawiasu. W tym znaczeniu „prowadnik” nie jest prowadnicą szuflady. [Blum][B1]. |
| Odległość puszki | Odległość od krawędzi frontu do krawędzi otworu puszki, według oznaczeń konkretnego systemu; u Blum: TB. Nie jest odległością do osi otworu. [Blum][B1]. |
| Prowadnica szuflady | Okucie prowadzące ruch szuflady względem korpusu. Typ, długość nominalna i wymagane miejsce montażu są osobnymi parametrami. [Hettich][H2]. |
| Skrzynka szuflady | Dno, boki i tył tworzące część pojemnikową szuflady, z przednią ścianką konstrukcyjną, jeżeli przewiduje ją system. Front dekoracyjny opisujemy osobno. |
| Pełny wysuw i częściowy wysuw | Określenia zakresu wysunięcia szuflady. Pełny wysuw daje dostęp do jej tylnej części; rzeczywistą drogę ruchu określa dokumentacja prowadnicy. [Hettich][H2]. |
| Cichy domyk | Funkcja hamowania końcowej fazy zamykania; nie oznacza otwierania przez naciśnięcie. Przykład: Silent System w [Hettich][H2]. |
| Otwieranie przez naciśnięcie, push to open | Funkcja wyzwalania otwarcia po naciśnięciu frontu; jej współpracę z domykaniem trzeba określić dla danego systemu. |
| Podnośnik frontu | Okucie sterujące ruchem i podtrzymaniem frontu unoszonego; sposób ruchu zależy od mechanizmu. |
| Cargo | Nazwa warsztatowa wysuwanego wyposażenia, zwykle z koszami lub półkami. W regule potrzebny jest konkretny typ mechanizmu. |
| Zawieszka i szyna montażowa | Zawieszka to element szafki współpracujący z mocowaniem ściennym; szyna jest listwą mocowaną do podłoża. „Listwa montażowa” w [STOL-014](cabinetry-rules.md#STOL-014) oznacza szynę do zawieszania. Sposób współpracy wynika z systemu. |
| System 32 | Zasada koordynacji wierceń i okuć oparta na rozstawie otworów 32 mm. Nie oznacza obowiązkowego rozstawu wszystkich otworów w każdym meblu. [Hettich][H1], sekcja Notes System 32. |

## Blat i jego połączenia

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Blat roboczy | Powierzchnia przeznaczona do pracy, zwykle nad szafkami dolnymi; materiał, grubość i sposób podparcia określamy oddzielnie. |
| Blat postformowany | Blat z laminatem przeprowadzonym przez profilowaną krawędź, bez osobnego złącza okładziny na tym zaokrągleniu. Przykład: [EGGER][E3]. |
| Blat kamienny, konglomerat, spiek | Różne rodziny materiałów: kamień naturalny, materiał ze spojonym kruszywem oraz materiał wytworzony przez spiekanie. Nazwy handlowe wymagają identyfikacji konkretnego produktu. |
| Nawis blatu | Część blatu wystająca poza określoną linię odniesienia. Nawis względem frontu i wspornikowy fragment bez podparcia nie zawsze są tym samym. [Cosentino Silestone][C1], sekcje Island overhangs. |
| Podparcie blatu | Element lub układ elementów przekazujący obciążenie blatu na konstrukcję. Jego ciągłość i rozstaw są cechami projektu. [Cosentino Dekton][C2]. |
| Złącze blatów | Miejsce i sposób połączenia oddzielnych części blatu; opis obejmuje geometrię styku, spoinę, mocowanie i podparcie. [Cosentino Silestone][C1]. |
| Złącze na ucios | Połączenie elementów z krawędziami obrobionymi pod kątem. „Łączenie narożne” nie określa samo, że zastosowano ucios. [Cosentino Silestone][C1], sekcja Waterfall edges. |
| Wycięcie w blacie | Otwór lub wybranie pod urządzenie, zlew albo inne wyposażenie. Kształt i promienie naroży są częścią jego geometrii. [Cosentino Dekton][C2]. |
| Zlew wpuszczany od góry | Zlew osadzony w otworze blatu z rantem opartym na jego górnej powierzchni; odpowiada montażowi top-mounted. [Cosentino Silestone][C1]. |
| Zlew podwieszany | Zlew zamocowany pod blatem; jego krawędź nie opiera się na górnej powierzchni. Termin opisuje położenie, nie kompletny sposób mocowania. |
| Montaż na równi z blatem | Osadzenie rantu zlewu lub urządzenia w wybraniu tak, aby jego górna powierzchnia była zlicowana z blatem; flush-mounted. [Cosentino Silestone][C1]. |
| Zlew nakładany na szafkę | Zlew zajmujący górę przewidzianej dla niego szafki, zastępujący tam fragment blatu. Odróżniamy go od zlewu wpuszczanego w otwór blatu. |
| Listwa przyblatowa i panel ścienny | Listwa wykańcza styk blatu ze ścianą; panel jest okładziną większego obszaru ściany. Ich funkcje i sposób uszczelnienia opisujemy osobno. |
| Uszczelnienie | Rozwiązanie ograniczające przenikanie wilgoci do styku lub materiału. Samo wskazanie „silikon” nie opisuje całego rozwiązania. |
| Szczelina dylatacyjna | Przestrzeń przewidziana na względne przemieszczenia elementów. Jej funkcja różni się od szczeliny dekoracyjnej. |

## Wymiary i przygotowanie wykonania

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Wymiar zewnętrzny korpusu | Odległość między skrajnymi powierzchniami korpusu w danym kierunku; front i wystające okucia uwzględnia się tylko przy jawnym wskazaniu. |
| Wymiar w świetle | Dostępna odległość między wewnętrznymi powierzchniami ograniczającymi przestrzeń. Nie oznacza automatycznie przestrzeni użytkowej po montażu okuć. |
| Wymiar frontu | Szerokość i wysokość samego frontu; nie można go utożsamiać z wymiarem zewnętrznym korpusu. |
| Wymiar całkowity zabudowy | Zasięg zmontowanego zespołu w danym kierunku, z określoną listą wliczanych elementów, np. panelem końcowym i blatem. |
| Wysokość robocza | Odległość od ustalonego poziomu wykończonej podłogi do górnej powierzchni blatu; obejmuje podparcie, korpus i blat zgodnie z konstrukcją. |
| Wymiar nominalny | Wartość służąca do oznaczania lub planowania elementu. Może różnić się od jego rzeczywistego wymiaru lub drogi ruchu. Przykład rozróżnienia dla prowadnic: [Hettich][H2]. |
| Formatka | Płaski element przygotowywany z materiału płytowego; opis wymaga wymiarów, materiału, orientacji i obróbki. |
| Wymiar cięcia i wymiar gotowy | Wymiar cięcia dotyczy elementu na określonym etapie rozkroju; gotowy — po przewidzianej obróbce, np. oklejeniu. Trzeba jawnie wskazać etap. |
| Wymiar formatki netto | W konwencji filmu 2: wymiar płyty bez obrzeża; źródło nazywa obrzeże „okleiną”. Nie rozstrzyga dodatkowych naddatków obróbkowych — [STOL-019](cabinetry-rules.md#STOL-019). |
| Wymiar formatki brutto | W konwencji filmu 2: wymiar elementu wraz z obrzeżem. Zrzut przedstawia wybór konwencji, bez wskazania przyjętego wariantu — [STOL-019](cabinetry-rules.md#STOL-019). |
| Rozkrój i lista formatek | Rozkrój określa układ i sposób wycięcia elementów z arkusza; lista formatek określa potrzebne elementy, ilości oraz parametry. |
| Tolerancja wymiarowa | Dopuszczalny zakres odchylenia wymiaru wykonanego od wymiaru określonego. Nie jest celowo pozostawionym luzem montażowym. |
| Baza pomiarowa | Punkt, krawędź, powierzchnia lub oś, od której określamy inne wymiary. |
| Głębokość bazowa i głębokość z frontem | W dostarczonym diagramie głębokość bazowa oznacza zasięg od tylnej ściany do przedniej linii korpusu, a głębokość z frontem uwzględnia też front. Dla krótszego boku zasięg zawiera przestrzeń za korpusem; nie jest samym wymiarem formatki — [STOL-039](cabinetry-rules.md#STOL-039). |
| Wręg GWR w konstrukcji D-K3 | Źródłowa nazwa pola „Głębokość wręgu” w aplikacji; w pokazanym przykładzie GWR ma 50 mm i odpowiada różnicy głębokości boków 570/520. Odróżniamy ten parametr od rowka pleców i ogólnego terminu wręg — [STOL-038](cabinetry-rules.md#STOL-038). |

Do opisów przyjmujemy roboczo: szerokość od lewej do prawej, wysokość od dołu do góry, głębokość od przodu do tyłu, patrząc na szafkę od strony użytkownika. Na liście formatek podajemy nazwy wymiarów i kierunek dekoru; kolejność dwóch liczb bez legendy nie jest wystarczająca.

## Montaż i warunki pracy zabudowy

| Pojęcie | Znaczenie w tym dokumencie |
| --- | --- |
| Inwentaryzacja pomieszczenia | Pomiar geometrii, otworów, instalacji i przeszkód w stanie określonym w opisie, np. po wykończeniu podłogi i ścian. |
| Poziomowanie i pionowanie | Ustawienie odpowiednio w poziomie i w pionie względem przyjętej bazy. Obie czynności różnią się od wzajemnego wyrównania frontów. |
| Prostokątność korpusu | Zachowanie kątów prostych i wymaganej geometrii konstrukcji; kontrola przekątnych może wspierać ocenę, ale nie opisuje sama całej geometrii przestrzennej. |
| Docinanie do ściany, trasowanie | Przeniesienie rzeczywistego przebiegu ściany na element i dopasowanie jego krawędzi, np. na blendzie. |
| Luz montażowy | Przestrzeń przewidziana na wstawienie, ustawienie i połączenie elementu. Występuje w określonym miejscu, nie jako ogólny dodatek do każdego wymiaru. |
| Przestrzeń instalacyjna | Miejsce na przewody, rury, przyłącza i inne instalacje; odróżniamy je od przestrzeni użytkowej szafki. |
| Odsunięcie od ściany | Odległość między wskazaną powierzchnią ściany a wskazaną granicą mebla. W opisie potrzebne są kierunek, baza i wartość; odsunięcie nie określa samo funkcji powstałej przestrzeni. Przykład: [STOL-013](cabinetry-rules.md#STOL-013). |
| Wnęka urządzenia | Przestrzeń przewidziana do zabudowy konkretnego AGD, opisana wymiarami i wymaganiami jego instrukcji. |
| Przekrój wentylacyjny | Pole wolnej drogi przepływu powietrza; może być mniejsze od zewnętrznego pola kratki lub otworu. |
| Dostęp serwisowy | Możliwość dojścia do elementów wymagających obsługi, odłączenia, regulacji albo wymiany. |
| Nośność i obciążenie | Nośność określa zdolność przenoszenia obciążeń w danych warunkach; obciążenie opisuje rzeczywiste lub projektowane oddziaływanie. |
| Ugięcie | Odkształcenie elementu pod obciążeniem, np. półki lub blatu; nie jest tym samym co trwałe uszkodzenie. |
| Droga przenoszenia obciążeń | Kolejne elementy, przez które obciążenie trafia z wyposażenia i mebla do podłogi lub ściany. |
| Mocowanie do podłoża, kotwienie | Połączenie zabudowy z odpowiednio rozpoznaną ścianą lub podłogą. Wybór mocowania zależy od podłoża i obciążeń. |

## Rozróżnienia potrzebne przy zapisie reguł

- „Szafka 600” wymaga wskazania, czy 600 oznacza szerokość modułu, zewnętrzną szerokość korpusu, czy inny wymiar, oraz podania jednostki.
- „Odjąć grubość płyty” wymaga wskazania elementu i sposobu połączenia. Dno między bokami oraz dno pod bokami mają inne relacje wymiarowe.
- „Szczelina” wymaga określenia, czy chodzi o fugę frontów, luz ruchowy, luz montażowy, dylatację czy drogę wentylacji.
- „Płyta laminowana” wymaga określenia rdzenia i rodzaju powierzchni. „Wilgocioodporna” nie oznacza automatycznie wodoszczelnego mebla.
- „Mocny blat” nie określa dopuszczalnego nawisu, rozstawu podpór ani położenia otworów. Warunki dla dwóch materiałów trzeba rozpatrywać w ich własnych instrukcjach: [Silestone][C1] i [Dekton][C2].
- Nazwa producenta lub serii okuć nie zastępuje numeru produktu, wariantu i właściwej dokumentacji montażowej.

## Jak będziemy dopisywać reguły

Każdy kolejny zapis w [rejestrze reguł](cabinetry-rules.md) powinien wskazywać: treść reguły, elementy których dotyczy, warunki zastosowania, parametry i jednostki, wyjątki, źródło wraz z wersją oraz sposób sprawdzenia. Oddzielimy wymaganie producenta, zależność geometryczną, praktykę warsztatową i preferencję estetyczną. Robocza propozycja pozostanie oznaczona do czasu jej potwierdzenia.

Pierwszym tematem dalszego rozpoznania będzie korpus: wzajemne położenie boków i wieńców, osadzenie pleców, połączenia oraz wymiarowanie formatek. Materiał i rozwiązanie okuć trzeba znać przed ustalaniem zależnych od nich wymiarów.
